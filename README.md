# Sevinch uchun 13 yosh sovg'asi 🎁

## Ishga tushirish
```bash
npm install
copy .env.example .env
npm run dev
```

`.env` ichiga:
- `ADMIN_PASSWORD` — boshqaruv paneli paroli
- `TELEGRAM_BOT_TOKEN` — BotFather bergan token
- `TELEGRAM_ADMIN_ID` — faqat sizning Telegram ID'ingiz

Brauzer: `http://localhost:3000`

Admin panel: `http://localhost:3000/admin.html`

Telegram botga admin sifatida rasm yoki video yuboring. U avtomatik galereyaga qo'shiladi.
